# Combats Arena — Браузерна RPG (Node.js + MongoDB + Docker Compose)

Браузерна гра у стилі **Combats (Бійцівський Клуб)** із покроковими боями по зонах, ботами, **PvP-дуелями між гравцями**, **магазином та екіпіруванням**, спрощеною реєстрацією, адмін-панеллю CRUD (включно з покращенням характеристик персонажів) та веб-панеллю керування MongoDB (**Mongo Express** — аналог phpMyAdmin).

## Стек технологій

- **Backend:** Node.js 20, Express, Mongoose, JWT, bcryptjs
- **Database:** MongoDB 7 (з постійним volume `mongo_data`)
- **DB Admin UI:** Mongo Express (порт `8081`)
- **Frontend:** Vanilla HTML/CSS/JS (dark RPG інтерфейс)
- **Інфраструктура:** Docker + Docker Compose

## Швидкий запуск

1. Створіть `.env` із шаблону та **обов'язково** задайте власні секрети (`.env` не комітиться):
   ```bash
   cp .env.example .env
   # JWT_SECRET: щонайменше 32 випадкових символи, наприклад
   openssl rand -hex 32
   ```
   `JWT_SECRET`, `ADMIN_PASSWORD` (≥ 8 символів), `MONGO_ROOT_PASS`, `MONGO_EXPRESS_PASS` обов'язкові — без них контейнери/сервер не стартують.
2. Запустіть контейнери:
   ```bash
   docker compose up --build -d
   ```

## Доступ до сервісів

| Сервіс | URL |

| **Гра Combats Arena** | http://localhost:3000 (адмін — `ADMIN_USERNAME` / `ADMIN_PASSWORD` з `.env`) |

## Додаткові змінні оточення

`CORS_ORIGIN` (список origin через кому; за замовчуванням лише same-origin), `TRUST_PROXY` (для коректного IP за reverse proxy), `JWT_EXPIRES_IN` (за замовчуванням `12h`), `AUTH_RATE_LIMIT`, `API_RATE_LIMIT`, `PVP_TURN_TIMEOUT_SEC` (300), `PVP_CHALLENGE_TTL_SEC` (900), `GROUP_TURN_TIMEOUT_SEC` (60), `GROUP_LOBBY_TTL_SEC` (900).

## Основні можливості

- **Спрощена реєстрація:** лише нікнейм та пароль — персонаж створюється миттєво.
- **Бойова система Combats (PvE та PvP):** вибір 1 зони удару (*Голова, Груди, Пояс, Ноги*) та 2 суміжних зон блоку; розрахунок шкоди (Сила + зброя), поглинання броні, ухилення (Спритність), критичного удару з пробиттям блоку (Інтуїція) та HP (Витривалість).
- **Екіпірування та Магазин:** 4 слоти (*Зброя, Броня, Шолом, Кільце*), 8 стартових предметів у лавці, купівля за золото, одягання/зняття з автоматичним перерахунком бонусів і `maxHp`, продаж за 50% вартості.
- **PvP між гравцями:** створення відкритої заявки на дуель, прийняття виклику іншим гравцем, синхронна подача прихованих ходів (раунд розраховується щойно обидва гравці зробили вибір) та автооновлення стану кожні 2.5 секунди. Для тестування PvP локально відкрийте гру у двох різних браузерах (або у звичайному вікні та режимі інкогніто).
- **Боти для боїв:** при першому запуску автоматично створюються 3 боти (*Тіньовий Новобранець*, *Вартовий Арени*, *Залізний Берсерк*).
- **Адмін-панель:**
  - Повний **CRUD персонажів** + швидке покращення характеристик у один клік (`+1 Сила`, `+1 Спритність`, `+1 Інтуїція`, `+1 Витривалість`, `+1 Рівень`, `+100 Золота`).
  - Повний **CRUD ботів арени** та **CRUD предметів магазину**.
  - Вкладка **«Дані користувачів»**: IP та User-Agent при реєстрації й останньому вході, час активності, кількість входів, історія входів (90 днів), відомі IP, кількість боїв, блокування/розблокування акаунтів.
- **Рейтинг (Elo):** змінюється після PvP-боїв (перемога, здача, тайм-аут), таблиця лідерів — вкладка «Рейтинг».
- **Загальний чат у реальному часі** (Socket.IO, авторизація JWT, ліміт 5 повідомлень / 10 с, історія 50 повідомлень, зберігання 7 днів).
- **Аватар і стать:** SVG-аватар (стать, шкіра, зачіска, головний убір, одяг, низ, взуття, аксесуари) з редактором у профілі; адмін може змінити вигляд будь-якого гравця кнопкою «Вигляд» в адмін-панелі.
- **Смуга HP** змінює колір: зелена (>60%), жовта (30–60%), червона (<30%).
- **Безпека:** helmet, rate limit, валідація (zod), атомарні покупки та PvP-ходи, автозавершення неактивних PvP-боїв.

### Групові бої, клани, квести

- **Групові бої** (вкладка «Групові бої»): PvP командами 1×1–3×3 та **підземелля з босами** (Катакомби, Печера орків, Лігво дракона; 3 поверхи, ціль для атаки вибирається вручну). Усі учасники ходять одночасно; якщо хтось мовчить `GROUP_TURN_TIMEOUT_SEC`, хід робиться випадково, після 3 пропусків гравець вибуває.
- **Клани**: створення (500 золота), вступ, внески до скарбниці, передача лідерства, виключення; клан отримує XP за перемоги; тег показується в рейтингу й чаті.
- **Щоденні квести та досягнення**: прогрес рахується автоматично, нагороди забираються у вкладці «Квести».

- **Навички та магія** (вкладка «Навички»): 6 навичок (потужний удар, вогняна куля, зцілення, кам'яна шкіра, вихор клинків, блискавка), вивчаються за золото з певного рівня. У груповому бою є мана (росте з інтуїцією, +5 за раунд) і перезарядки.
- **Адмін → «Клани»**: перегляд, редагування назви/тегу/скарбниці/XP, склад, призначення лідера, виключення, розпуск.

### Перенесення бази між копіями

```
./scripts/backup.sh            # створює backup-ДАТА.gz
./scripts/restore.sh backup.gz # перезаписує базу з дампу
```

Переноси дамп від свіжішої копії до старішої. Файли `backup-*.gz` не комітяться.

## Тести зі шкільних знань (золото)

Гравець відповідає на запитання у вкладці «Знання» й отримує золото за правильну відповідь.
Кожне запитання можна відповісти лише один раз (неправильна відповідь теж «спалює» його).
Варіантів до 4 — одна правильна, понад 4 — може бути кілька.

Адмін імпортує запитання у розділі «Адмін → Тести» (вставка тексту або файл `.json`):

```json
{
  "subject_id": 1, "class_id": 1, "topic_id": 1,
  "subject_name": "Інформатика", "class_name": "7 клас", "topic_name": "Види комп'ютерів",
  "source_url": "https://...",
  "questions": [
    { "text": "Питання?", "answers": [
      { "text": "а) Варіант", "is_correct": false },
      { "text": "б) Варіант", "is_correct": true }
    ] }
  ]
}
```

Можна передати й масив таких об'єктів. Повторний імпорт оновлює запитання (дедуплікація за хешем).
Змінні середовища: `QUIZ_REWARD_GOLD` (за замовчуванням 10), `QUIZ_DAILY_GOLD_CAP` (300 на добу).
