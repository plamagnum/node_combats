# Combats Arena — Браузерна RPG (Node.js + MongoDB + Docker Compose)

Браузерна гра у стилі **Combats (Бійцівський Клуб)** із покроковими боями по зонах, ботами, **PvP-дуелями між гравцями**, **магазином та екіпіруванням**, спрощеною реєстрацією, адмін-панеллю CRUD (включно з покращенням характеристик персонажів) та веб-панеллю керування MongoDB (**Mongo Express** — аналог phpMyAdmin).

## Стек технологій

- **Backend:** Node.js 20, Express, Mongoose, JWT, bcryptjs
- **Database:** MongoDB 7 (з постійним volume `mongo_data`)
- **DB Admin UI:** Mongo Express (порт `8081`)
- **Frontend:** Vanilla HTML/CSS/JS (dark RPG інтерфейс)
- **Інфраструктура:** Docker + Docker Compose

## Швидкий запуск

1. Розпакуйте архів і перейдіть у папку проєкту:
   ```bash
   cd combats-game
   ```
2. (Необов'язково) Скопіюйте `.env.example` у `.env` та змініть паролі/порти за потреби:
   ```bash
   cp .env.example .env
   ```
3. Запустіть усі контейнери:
   ```bash
   docker compose up --build -d
   ```

## Основні можливості

- **Спрощена реєстрація:** лише нікнейм та пароль — персонаж створюється миттєво.
- **Бойова система Combats (PvE та PvP):** вибір 1 зони удару (*Голова, Груди, Пояс, Ноги*) та 2 суміжних зон блоку; розрахунок шкоди (Сила + зброя), поглинання броні, ухилення (Спритність), критичного удару з пробиттям блоку (Інтуїція) та HP (Витривалість).
- **Екіпірування та Магазин:** 4 слоти (*Зброя, Броня, Шолом, Кільце*), 8 стартових предметів у лавці, купівля за золото, одягання/зняття з автоматичним перерахунком бонусів і `maxHp`, продаж за 50% вартості.
- **PvP між гравцями:** створення відкритої заявки на дуель, прийняття виклику іншим гравцем, синхронна подача прихованих ходів (раунд розраховується щойно обидва гравці зробили вибір) та автооновлення стану кожні 2.5 секунди. Для тестування PvP локально відкрийте гру у двох різних браузерах (або у звичайному вікні та режимі інкогніто).
- **Боти для боїв:** при першому запуску автоматично створюються 3 боти (*Тіньовий Новобранець*, *Вартовий Арени*, *Залізний Берсерк*).
- **Адмін-панель:**
  - Повний **CRUD персонажів** + швидке покращення характеристик у один клік (`+1 Сила`, `+1 Спритність`, `+1 Інтуїція`, `+1 Витривалість`, `+1 Рівень`, `+100 Золота`).
  - Повний **CRUD ботів арени** та **CRUD предметів магазину**.
